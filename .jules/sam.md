
## 2026-07-28 - API Reference Documentation Best Practices
**Learning:** Adding a complete API Reference to the docs folder provides users with direct, explicit methods for interacting with endpoints. Manually inspecting the exact TypeScript interfaces ensures the documented JSON payloads are accurate and not hallucinated.
**Action:** Always include complete, runnable cURL examples, document authentication/rate limit requirements, and explicitly extract JSON response payloads from route handlers/interfaces before constructing API references.
