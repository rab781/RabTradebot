## 2024-05-24 - Documenting API Reference with Explicit Types
**Learning:** Explicitly documenting API responses based on TypeScript interfaces prevents hallucinations and reduces developer friction when consuming endpoints.
**Action:** Always read the exact TypeScript interfaces and express route handlers (e.g., using `cat` or `grep`) to document endpoints with accurate JSON payloads, rate limits, and pagination parameters.
