
## 2024-06-29 - Documenting Implicit API States and Docs Folders
**Learning:** Developers often forget that missing features (like a lack of authentication) are just as critical to document as existing features. Implicit states confuse users. Also, standard repositories often ignore `docs/` folders by default, which can lead to uncommitted documentation.
**Action:** Always explicitly document authentication requirements (even if unauthenticated) and verify `.gitignore` configurations when introducing new documentation directories.
