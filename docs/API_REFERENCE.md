# Advanced Crypto Trading Bot API Reference

The Advanced Crypto Trading Bot provides a REST API to monitor the bot's state, view active positions, fetch signals, and check overall health.

## Base URL

By default, the web server runs on \`http://localhost:3000\`. In a production environment, this will match your \`WEB_HOST\` and \`WEB_PORT\` configuration.

## Authentication

The REST API currently runs **without authentication**. It is intended for internal or protected network access. If exposing the API publicly, it is strongly recommended to place it behind a reverse proxy (like Nginx) that handles authentication.

## Rate Limiting

The API implements a custom token bucket rate limiter to prevent abuse:
- **Limit:** 100 requests per minute per IP address.
- **Exceeded:** When the limit is exceeded, the API returns an HTTP \`429 Too Many Requests\` with the following payload:

\`\`\`json
{
  "error": "Too many requests, please try again later."
}
\`\`\`

## Pagination

Endpoints returning lists (such as \`/api/trades\`, \`/api/signals\`, and \`/api/news\`) support pagination via the \`limit\` query parameter.
- Example: \`GET /api/trades?limit=10\`
- If no \`limit\` is provided, default limits apply (50 for trades, 20 for signals and news).

## Error Handling

All unexpected server errors return an HTTP \`500 Internal Server Error\` response with a standard error message:

\`\`\`json
{
  "error": "An internal server error occurred"
}
\`\`\`

### 2. Get All Trades
Retrieves a list of recent trades (both open and closed).

- **URL:** \`/api/trades\`
- **Method:** \`GET\`
- **Query Params:** \`limit\` (optional, default: 50)

**Example Request:**
\`\`\`bash
curl -X GET "http://localhost:3000/api/trades?limit=5"
\`\`\`

**Example Response:**
\`\`\`json
[
  {
    "id": "67890",
    "symbol": "ETHUSDT",
    "action": "SELL",
    "price": 3500,
    "quantity": 0.5,
    "timestamp": "2023-10-15T10:30:00.000Z",
    "status": "OPEN"
  }
]
\`\`\`
