# API Reference

The REST API provides access to the bot's real-time state, including active trades, generated signals, market news, and portfolio performance.

## Base URL

All API requests should be prefixed with the configured base URL (default: `http://localhost:3000/api`).

## Authentication

By default, the REST API runs **without authentication**. It is designed for local dashboard access or internal network monitoring.

> **Warning**: Do not expose this API directly to the public internet without placing it behind a reverse proxy (like Nginx) with authentication and TLS.

## Rate Limiting

To prevent abuse and memory exhaustion, the API enforces rate limits on all endpoints under `/api`.

- **Limit**: 100 requests per minute per IP address
- **Exceeded Limit Response**: HTTP `429 Too Many Requests`
- **Error Format**: `{"error": "Too many requests, please try again later."}`

## Pagination

Some endpoints that return lists of items support pagination via the `limit` query parameter. If not provided, the API uses a default limit suitable for each endpoint.

Example:
```
GET /api/trades?limit=100
```

## Error Handling

When an error occurs, the API will return an appropriate HTTP status code and a JSON response containing an `error` message.

- `400 Bad Request`: The request was invalid or malformed.
- `429 Too Many Requests`: Rate limit exceeded.
- `500 Internal Server Error`: An unexpected error occurred on the server.

Example Error Response:
```json
{
  "error": "An internal server error occurred"
}
```

## Endpoints

### Get Dashboard Data
Retrieves the aggregated dashboard overview.

- **URL**: `/api/dashboard`
- **Method**: `GET`
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**: Aggregated dashboard JSON data.

### Get Trades
Retrieves a list of recent trades.

- **URL**: `/api/trades`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (number, optional): Maximum number of trades to return. Defaults to 50.
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**: Array of trade objects.

### Get Open Trades
Retrieves all currently open trading positions.

- **URL**: `/api/trades/open`
- **Method**: `GET`
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**: Array of open trade objects.

### Get Signals
Retrieves recent trading signals generated by the bot.

- **URL**: `/api/signals`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (number, optional): Maximum number of signals to return. Defaults to 20.
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**: Array of signal objects.

### Get News
Retrieves recent market news and AI sentiment analysis.

- **URL**: `/api/news`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (number, optional): Maximum number of news items to return. Defaults to 20.
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**: Array of news objects.

### Get Portfolio
Retrieves the current portfolio balance and metrics.

- **URL**: `/api/portfolio`
- **Method**: `GET`
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**: Portfolio metrics object.

### Get Bot Stats
Retrieves the bot's runtime statistics and performance metrics.

- **URL**: `/api/stats`
- **Method**: `GET`
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**: Bot statistics object.

### Internal API Health Check
A lightweight health check for the internal API router.

- **URL**: `/api/health`
- **Method**: `GET`
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**:
    ```json
    {
      "status": "OK",
      "timestamp": "2023-10-25T12:00:00.000Z",
      "uptime": 3600
    }
    ```

### External Monitoring Health Check
A comprehensive health snapshot intended for external monitoring tools. Note that this endpoint is **not** under the `/api` prefix and is not subject to the same rate limiting.

- **URL**: `/health`
- **Method**: `GET`
- **Success Responses**:
  - **Code**: `200 OK` (if healthy)
  - **Code**: `503 Service Unavailable` (if overall status is 'down')
  - **Content**:
    ```json
    {
      "status": "healthy",
      "timestamp": "2023-10-25T12:00:00.000Z",
      "uptime": 3600,
      "memoryUsageMb": 150.5,
      "requestCount": 42,
      "components": { ... }
    }
    ```
