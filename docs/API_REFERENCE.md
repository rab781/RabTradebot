# Advanced Crypto Trading Bot API Reference

> REST API for state management, dashboard data, and health monitoring of the Advanced Crypto Trading Bot.

## Base URL
All API requests should be prefixed with `/api` unless otherwise specified.
Example: `http://localhost:3000/api`

## Authentication
Currently, the REST API runs **without authentication**. It is designed to be accessed locally or within a secure private network. Ensure proper network-level security (e.g., firewalls, VPNs) if exposing the API externally.

## Rate Limiting
Requests are limited to **100 requests per minute per IP address**.
If the limit is exceeded, a `429 Too Many Requests` response is returned.

```json
{
  "error": "Too many requests, please try again later."
}
```

## Pagination
Several endpoints support pagination via the `limit` query parameter.
- `limit` (optional): Number of items to return. Defaults vary per endpoint (e.g., 50 for trades, 20 for signals and news).

## Endpoints

### 1. Dashboard Data
Aggregated data for the web dashboard, including trades, signals, news, portfolio, stats, and open trades.

**Endpoint:** `GET /api/dashboard`

**Example Request:**
```bash
curl http://localhost:3000/api/dashboard
```

**Example Response:**
```json
{
  "trades": [],
  "signals": [],
  "news": [],
  "portfolio": {
    "totalValue": 10000,
    "positions": [],
    "performance": {
      "totalPnl": 0,
      "totalPnlPercentage": 0,
      "winRate": 0,
      "totalTrades": 0
    }
  },
  "stats": {
    "uptime": 3600000,
    "totalCommands": 150,
    "activeUsers": 5,
    "lastUpdate": "2023-10-27T10:00:00.000Z"
  },
  "openTrades": []
}
```

### 2. Trades
Get a list of recent trades.

**Endpoint:** `GET /api/trades`

**Query Parameters:**
- `limit` (integer, optional): Maximum number of trades to return (default: 50, max: 100).

**Example Request:**
```bash
curl "http://localhost:3000/api/trades?limit=10"
```

**Example Response:**
```json
[
  {
    "id": "12345",
    "symbol": "BTCUSDT",
    "action": "BUY",
    "price": 34000.5,
    "quantity": 0.1,
    "timestamp": "2023-10-27T09:30:00.000Z",
    "status": "CLOSED",
    "profit": 150.25
  }
]
```

## Error Handling
In case of an internal server error or invalid request, the API will return a standard JSON error structure with the appropriate HTTP status code (e.g., `500 Internal Server Error`, `429 Too Many Requests`).

```json
{
  "error": "An internal server error occurred"
}
```
