# REST API Reference

The Trading Bot provides a REST API for accessing market data, bot state, and trading history.

## Authentication

The REST API currently runs without authentication. You ensure you expose the API port safely behind a reverse proxy or firewall.

## Rate Limiting

Requests are limited to 100 requests per minute per IP address. If you exceed this limit, the API returns an HTTP `429 Too Many Requests` status code.

```json
{
  "error": "Too many requests, please try again later."
}
```

## Pagination

Endpoints that return lists support pagination via the `limit` query parameter.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | `integer` | Varies | Maximum number of records to return |

## Error Handling

Standard error responses use appropriate HTTP status codes and return a JSON body with an `error` message.

```json
{
  "error": "An internal server error occurred"
}
```

## Endpoints

### Get Dashboard Data

Retrieves the current state of the dashboard, including summary metrics.

**GET** `/api/dashboard`

**Response (200 OK)**

```json
{
  "status": "active",
  "uptime": 3600
}
```

### Get Trades

Retrieves historical trading data.

**GET** `/api/trades`

**Query Parameters**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | `integer` | `50` | Maximum number of trades to return |

### Get Open Trades

Retrieves all currently open positions.

**GET** `/api/trades/open`

### Get Signals

Retrieves recent trading signals generated by the bot.

**GET** `/api/signals`

**Query Parameters**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | `integer` | `20` | Maximum number of signals to return |

### Get News

Retrieves recent news analysis and market sentiment data.

**GET** `/api/news`

**Query Parameters**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | `integer` | `20` | Maximum number of news items to return |

### Get Portfolio

Retrieves the current portfolio status and balances.

**GET** `/api/portfolio`

### Get Bot Statistics

Retrieves performance statistics for the bot's operation.

**GET** `/api/stats`

### Get API Health

Retrieves basic health information for the API.

**GET** `/api/health`

### Get System Health

Retrieves detailed system health monitoring metrics.

**GET** `/health`

**Response (200 OK / 503 Service Unavailable)**

Returns `200 OK` if the system is healthy, or `503 Service Unavailable` if critical components are down.
