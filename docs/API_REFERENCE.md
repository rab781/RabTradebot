# Advanced Crypto Trading Bot - API Reference

The REST API allows you to retrieve real-time data, trades, signals, and bot statistics from the Advanced Crypto Trading Bot. All endpoints return data in JSON format.

## Base URL

By default, the Web Dashboard and API run on port `3000`.

```
http://localhost:3000
```

## Authentication

Currently, the REST API endpoints are public and do not require authentication headers or API keys. (Ensure your CORS and network settings restrict access appropriately if deploying in production).

## Rate Limiting

Endpoints under the `/api` route are strictly rate-limited to prevent abuse and memory exhaustion.

*   **Limit:** 100 requests per 1 minute per IP address.
*   **Exceeded Limit Response:** If you exceed the rate limit, the API returns a `429 Too Many Requests` HTTP status code.

**Rate Limit Error Response:**
```json
{
  "error": "Too many requests, please try again later."
}
```

## General Error Handling

If an internal server error occurs, endpoints will return a `500 Internal Server Error` status.

**Internal Server Error Response:**
```json
{
  "error": "An internal server error occurred"
}
```

## Endpoints

### 1. Get Dashboard Data

Retrieves aggregated data to populate a complete dashboard view, including recent trades, signals, news, portfolio summary, and stats.

*   **URL:** `/api/dashboard`
*   **Method:** `GET`
*   **Query Parameters:** None

**Example Request:**
```bash
curl -X GET http://localhost:3000/api/dashboard
```

**Example Response:**
```json
{
```

### 2. Get Trades

Retrieves the most recent trades executed by the bot.

*   **URL:** `/api/trades`
*   **Method:** `GET`
*   **Query Parameters:**
    *   `limit` (optional): Number of trades to return (default is 50).

**Example Request:**
```bash
curl -X GET "http://localhost:3000/api/trades?limit=10"
```

**Example Response:**
```json
[
  {
    "id": "trade_123",
    "symbol": "BTCUSDT",
    "action": "BUY",
    "price": 64000.5,
    "quantity": 0.1,
    "timestamp": "2023-10-27T10:00:00.000Z",
    "profit": null,
    "status": "OPEN"
  }
]
```
