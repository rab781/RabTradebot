# API Reference

The RabTradebot provides a REST API for monitoring and displaying bot status. The API runs without authentication by default but enforces rate limiting to protect endpoints from abuse.

## Authentication
Currently, the REST API does not require authentication.

## Rate Limiting
Requests are limited to 100 requests per minute per IP address. If the rate limit is exceeded, the server will return an HTTP 429 error.

## Endpoints

### Dashboard
Retrieves overall dashboard metrics.

**Endpoint**: `GET /api/dashboard`

**Response Example (200 OK)**:
```json
{
  "totalTrades": 150,
  "winRate": 65.5,
  "totalProfit": 1250.50,
  "currentBalance": 11250.50
}
```

### Trades
Retrieves a list of recent trades.

**Endpoint**: `GET /api/trades`

**Query Parameters**:
| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `limit` | `number` | `50` | Maximum number of trades to return |

**Response Example (200 OK)**:
```json
[
  {
    "id": "trd_123",
    "symbol": "BTCUSDT",
    "type": "BUY",
    "price": 50000,
    "amount": 0.1,
    "timestamp": "2024-05-18T10:00:00Z"
  }
]
```

### Open Trades
Retrieves currently open trades.

**Endpoint**: `GET /api/trades/open`

**Response Example (200 OK)**:
```json
[
  {
    "id": "trd_124",
    "symbol": "ETHUSDT",
    "type": "BUY",
    "entryPrice": 3000,
    "amount": 1.5,
    "unrealizedPnL": 45.0,
    "timestamp": "2024-05-18T10:30:00Z"
  }
]
```

### Signals
Retrieves recent trading signals generated by the bot.

**Endpoint**: `GET /api/signals`

**Query Parameters**:
| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `limit` | `number` | `20` | Maximum number of signals to return |

**Response Example (200 OK)**:
```json
[
  {
    "symbol": "SOLUSDT",
    "action": "BUY",
    "confidence": 0.85,
    "reason": "RSI oversold and MACD crossover",
    "timestamp": "2024-05-18T11:00:00Z"
  }
]
```

### News
Retrieves recent news sentiment analyses.

**Endpoint**: `GET /api/news`

**Query Parameters**:
| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `limit` | `number` | `20` | Maximum number of news items to return |

**Response Example (200 OK)**:
```json
[
  {
    "title": "Bitcoin ETF Approval Expected",
    "sentiment": "POSITIVE",
    "score": 0.9,
    "timestamp": "2024-05-18T09:00:00Z"
  }
]
```

### Portfolio
Retrieves portfolio status including current balance and positions.

**Endpoint**: `GET /api/portfolio`

**Response Example (200 OK)**:
```json
{
  "totalBalance": 15000,
  "availableFiat": 5000,
  "positions": [
    {
      "symbol": "BTC",
      "amount": 0.2,
      "currentValue": 10000
    }
  ]
}
```

### Stats
Retrieves overall bot performance and system statistics.

**Endpoint**: `GET /api/stats`

**Response Example (200 OK)**:
```json
{
  "uptimeSeconds": 86400,
  "memoryUsageMB": 125,
  "activeConnections": 10
}
```

### Health Check (API)
Checks the basic health of the API web server.

**Endpoint**: `GET /api/health`

**Response Example (200 OK)**:
```json
{
  "status": "OK",
  "timestamp": "2024-05-18T12:00:00.000Z",
  "uptime": 3600
}
```

### Health Monitoring (System)
Checks the system-level health status of the entire application.

**Endpoint**: `GET /health`

**Response Example (200 OK)**:
```json
{
  "status": "healthy",
  "components": {
    "database": "healthy",
    "binanceApi": "healthy"
  }
}
```

## Errors

Standard HTTP error codes are used.

- `400 Bad Request`: Invalid parameters.
- `429 Too Many Requests`: Rate limit exceeded.
- `500 Internal Server Error`: An internal server error occurred.

**Error Response Example (500 Internal Server Error)**:
```json
{
  "error": "An internal server error occurred"
}
```
