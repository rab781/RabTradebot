# Advanced Crypto Trading Bot API Reference

The Advanced Crypto Trading Bot REST API allows you to monitor the bot's state, view active and historical trades, check current trading signals and news sentiment, and inspect portfolio and health metrics.

## Authentication
Currently, the REST API does not require authentication. It is intended for internal dashboard consumption and monitoring.

## Rate Limiting
Requests are limited to **100 requests per minute per IP address**.
If you exceed this limit, the API will respond with HTTP `429 Too Many Requests`:
```json
{
  "error": "Too many requests, please try again later."
}
```

## Pagination
List endpoints support pagination via the `limit` query parameter.
- Trades default limit: `50`
- Signals default limit: `20`
- News default limit: `20`

## State & Monitoring

### `GET /api/dashboard`
Returns a consolidated overview of the bot's current state, including recent trades, signals, news, portfolio, and stats.

**Example Request:**
```bash
curl http://localhost:3000/api/dashboard
```

**Response Payload (`200 OK`):**
```json
{
  "trades": [],
  "signals": [],
  "news": [],
  "portfolio": {
    "totalValue": 10000,
    "positions": [],
    "performance": {
      "totalPnl": 0,
      "totalPnlPercentage": 0,
      "winRate": 0,
      "totalTrades": 0
    }
  },
  "stats": {
    "uptime": 3600,
    "totalCommands": 10,
    "activeUsers": 1,
    "lastUpdate": "2023-10-25T10:00:00Z"
  },
  "openTrades": []
}
```

### `GET /api/stats`
Returns current bot operational statistics.

**Example Request:**
```bash
curl http://localhost:3000/api/stats
```

**Response Payload (`200 OK`):**
```json
{
  "uptime": 3600,
  "totalCommands": 10,
  "activeUsers": 1,
  "lastUpdate": "2023-10-25T10:00:00Z"
}
```

### `GET /api/portfolio`
Returns current portfolio state and performance metrics.

**Example Request:**
```bash
curl http://localhost:3000/api/portfolio
```

**Response Payload (`200 OK`):**
```json
{
  "totalValue": 10000,
  "positions": [
    {
      "symbol": "BTC/USDT",
      "quantity": 0.5,
      "averagePrice": 30000,
      "currentPrice": 31000,

  ],

    "totalPnlPercentage": 5.0,
    "winRate": 0.65,
    "totalTrades": 100
  }
}
```

## Trading Data

### `GET /api/trades`
Returns the recent trades executed by the bot.

**Parameters:**
- `limit` (optional): Number of trades to return (default: `50`).

**Example Request:**
```bash
curl http://localhost:3000/api/trades?limit=5
```

**Response Payload (`200 OK`):**
```json
[
  {
    "id": "trade_123",
    "symbol": "BTC/USDT",
    "action": "BUY",
    "price": 30000,
    "quantity": 0.5,
    "timestamp": "2023-10-25T10:00:00Z",
    "profit": 0,
    "status": "CLOSED"
  }
]
```

### `GET /api/trades/open`
Returns all currently open trades.

**Example Request:**
```bash
curl http://localhost:3000/api/trades/open
```

**Response Payload (`200 OK`):**
```json
[
  {
    "id": "trade_124",
    "symbol": "ETH/USDT",
    "action": "BUY",
    "price": 2000,
    "quantity": 10,
    "timestamp": "2023-10-25T11:00:00Z",
    "status": "OPEN"
  }
]
```

## Health & Diagnostics

### `GET /api/health`
Returns a simple health check of the web server.

**Example Request:**
```bash
curl http://localhost:3000/api/health
```

**Response Payload (`200 OK`):**
```json
{
  "status": "OK",
  "timestamp": "2023-10-25T10:00:00Z",
  "uptime": 3600
}
```
