# API Reference

> Complete API reference for the Advanced Crypto Trading Bot Web Server.

## Authentication
The API currently does not require authentication for reading public data. Ensure you set `CORS_ORIGIN` in your environment variables to restrict access appropriately.

## Rate Limiting
All `/api/*` requests are limited to **100 requests per minute** per IP address to prevent abuse.
When the rate limit is exceeded, the server responds with:
- **HTTP Status**: `429 Too Many Requests`
- **Response**: `{"error": "Too many requests, please try again later."}`

## Pagination
Endpoints returning lists of data (`/api/trades`, `/api/signals`, `/api/news`) support a `limit` query parameter to paginate results.
Example: `GET /api/trades?limit=10`

## Endpoints

### 1. Dashboard Data
Retrieves the comprehensive current dashboard state.

- **URL**: `/api/dashboard`
- **Method**: `GET`
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**: JSON object containing trades, signals, news, portfolio, and stats.
- **Error Response**:
  - **Code**: `500 Internal Server Error`
  - **Content**: `{"error": "An internal server error occurred"}`
- **Example Code**:
```bash
curl -X GET http://localhost:3000/api/dashboard
```

### 2. Trades History
Retrieves recent trades.

- **URL**: `/api/trades`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (number, optional, default: 50): Number of trades to retrieve.
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**: Array of trade objects.
- **Error Response**:
  - **Code**: `500 Internal Server Error`
  - **Content**: `{"error": "An internal server error occurred"}`
- **Example Code**:
```bash
curl -X GET "http://localhost:3000/api/trades?limit=10"
```

### 9. External Monitoring Health
Comprehensive health check for external monitoring services.

- **URL**: `/health`
- **Method**: `GET`
- **Success Response**:
  - **Code**: `200 OK`
  - **Content**: JSON object containing overall status, memory usage, request counts, and component status.

- **Example Code**:
```bash
curl -X GET http://localhost:3000/health
```

## WebSocket Events

The server provides real-time updates via Socket.IO. Connect to the base URL (e.g., `ws://localhost:3000`).

### Events Emitted by Server:
- `dashboard`: Emitted upon connection with the full initial dashboard state.
- `trade`: Emitted when a new trade is executed. Payload: Trade object.
- `signal`: Emitted when a new signal is generated. Payload: Signal object.
- `news`: Emitted when new news is analyzed. Payload: News object.
- `portfolio`: Emitted when the portfolio state changes. Payload: Portfolio object.
