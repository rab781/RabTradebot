# Advanced Crypto Trading Bot API Reference

The Advanced Crypto Trading Bot Web Dashboard API provides programmatic access to bot state, trades, signals, news, and overall performance statistics.

## Base URL
All API requests should be prefixed with the base URL of your web dashboard server (e.g., `http://localhost:3000`). Most functional endpoints use the `/api` prefix.

## Authentication
This API does not currently require authentication. It is intended for internal dashboard access. For internet-facing deployments, it is strongly recommended to restrict access via a reverse proxy (like Nginx) or VPN.

## Rate Limiting
Requests under the `/api` route are limited to 100 requests per minute per IP address. If this limit is exceeded, you will receive a `429 Too Many Requests` response.

### 2. Get Trades
Retrieves a list of recent trades executed by the bot.

**Endpoint:** `GET /api/trades`

**Query Parameters:**
- `limit` (optional, integer): Maximum number of trades to return (default: 50).

**Example Request:**
```bash
curl "http://localhost:3000/api/trades?limit=10"
```

**Example Response:**
```json
[
  {
    "id": "trade-124",
    "symbol": "ETHUSDT",
    "action": "SELL",
    "price": 2050,
    "quantity": 0.5,
    "timestamp": "2023-10-27T10:15:00.000Z",
    "profit": 25,
    "status": "CLOSED"
  }
]
```

### 9. Get Health (External)
Retrieves external monitoring system health details (used in production for healthchecks). Note that this endpoint is not prefixed with `/api/`. Returns a 503 HTTP status code if the system is not healthy.

**Endpoint:** `GET /health`

**Example Request:**

## Error Handling

Standard HTTP status codes are returned to indicate success or failure. In case of an error, the response body will contain a JSON object with an `error` field.

**Example Error Response (`500 Internal Server Error`):**
```json
{
  "error": "An internal server error occurred"
}
```

**Example Rate Limit Response (`429 Too Many Requests`):**
```json
{
  "error": "Too many requests, please try again later."
}
```
