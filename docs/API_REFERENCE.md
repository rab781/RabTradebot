# RabTradebot API Reference

Welcome to the RabTradebot API Reference. This API provides programmatic access to trading signals, market news, bot statistics, and your simulated portfolio. It is designed to power the forthcoming Web Dashboard (Phase 8).

## Overview

- **Base URL:** `http://localhost:3000/api` (default, can be configured via `WEB_PORT` and `WEB_HOST`)
- **WebSockets:** Real-time updates are available at the base URL using Socket.io.
- **Authentication:** Currently, the API is unauthenticated and intended for local/private network use. Ensure your server is not exposed to the public internet without a reverse proxy adding authentication.

## Rate Limiting

The API implements a custom rate limiter to prevent abuse:
- **Limit:** 100 requests per 60 seconds (1 minute) per IP address.
- **Exceeded:** Requests exceeding the limit will receive an HTTP `429 Too Many Requests` response.
- **Response Format:**
  ```json
  {
    "error": "Too many requests, please try again later."
  }
  ```

## Error Handling

Standard HTTP status codes are used to indicate success or failure:
- `200 OK`: Request successful.
- `429 Too Many Requests`: Rate limit exceeded.
- `500 Internal Server Error`: An unexpected error occurred on the server.

A typical error response body:
```json
{
  "error": "An internal server error occurred"
}
```

### 2. Get Trades

Retrieves a list of recent trades (both open and closed).

- **Method:** `GET`
- **Path:** `/trades`
- **Query Parameters:**
  - `limit` (optional, integer): Maximum number of trades to return. Defaults to `50`.
- **Example Request:**
  ```bash
  curl "http://localhost:3000/api/trades?limit=5"
  ```
- **Example Response:**
  ```json
  [
    {
      "id": "1710000000-BTCUSDT",
      "symbol": "BTCUSDT",
      "action": "BUY",
      "price": 65000.5,
      "quantity": 0.1,
      "timestamp": "2024-03-09T15:00:00.000Z",
      "profit": 150.25,
  ```

## WebSocket Events

The server provides real-time updates via Socket.io.

- **Connection URL:** `http://localhost:3000`
- **Initial State:** Upon connecting, the server immediately emits a `dashboard` event containing the same payload as the `/api/dashboard` endpoint.

### Available Events

- `dashboard`: Emitted on initial connection. Payload: Full Dashboard JSON.
- `trade`: Emitted when a new trade is opened or closed. Payload: Single `Trade` JSON object.
- `signal`: Emitted when a new signal is generated. Payload: Single `Signal` JSON object.
- `news`: Emitted when a new news item is processed. Payload: Single `NewsItem` JSON object.
- `portfolio`: Emitted when the portfolio is updated. Payload: Full `Portfolio` JSON object.

### Example WebSocket Client (JavaScript)

```javascript
import { io } from "socket.io-client";

const socket = io("http://localhost:3000");

socket.on("connect", () => {
  console.log("Connected to Real-time API");
});

socket.on("dashboard", (data) => {
  console.log("Initial Dashboard Data:", data);
});

socket.on("signal", (newSignal) => {
  console.log("🚨 New Signal:", newSignal);
});
```
