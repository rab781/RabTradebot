# RabTradebot REST API Reference

> The RabTradebot REST API provides programmatic access to bot state, trading performance, signals, and system health.

## Overview

- **Base URL:** `http://localhost:3000` (or your configured host/port)
- **Content Type:** All endpoints return `application/json`.

## Authentication

By default, the REST API runs **without authentication**. Ensure your server is properly secured via a firewall or reverse proxy if exposed to the public internet.

## Rate Limiting

The API enforces a rate limit of **100 requests per minute per IP address**.
If the limit is exceeded, the server will respond with a `429 Too Many Requests` status code.

**Rate Limit Response:**
```json
{
  "error": "Too many requests, please try again later."
}
```

## General Error Handling

If an internal error occurs while processing your request, the server will return a `500 Internal Server Error` status code.

**Error Response:**
```json
{
  "error": "An internal server error occurred"
}
```

## Pagination

Some endpoints return lists of data and support pagination via the `limit` query parameter.

- `limit` (optional): Maximum number of items to return. Defaults to 50 for trades and 20 for signals and news.

### 2. Get Trades
Retrieves a list of recent trades.

- **URL:** `/api/trades`
- **Method:** `GET`
- **Query Parameters:**
  - `limit` (number): Default `50`.

**Example Request:**
```bash
curl -X GET "http://localhost:3000/api/trades?limit=5"
```

**Example Response:**
```json
[
  {
    "id": "12345",
    "symbol": "BTCUSDT",
    "action": "BUY",
    "price": 60000,
    "quantity": 0.01,
    "timestamp": "2023-10-01T12:00:00.000Z",
    "status": "OPEN"
  }
]
```
