# API Reference

The Advanced Crypto Trading Bot provides a REST API for accessing trading data, signals, portfolio status, and system health.

## Authentication
Currently, the REST API does not require authentication and is intended for local or internal network use.

## Rate Limiting
Requests are limited to 100 requests per minute per IP address. If the limit is exceeded, a `429 Too Many Requests` response is returned.

## Pagination
List endpoints (like `/api/trades`, `/api/signals`, `/api/news`) support pagination via a `limit` query parameter.
- Trades default limit: 50
- Signals and News default limit: 20

## Error Handling
If an error occurs, the API returns a `500 Internal Server Error` with a JSON payload:
```json
{
  "error": "An internal server error occurred"
}
```

## Endpoints

### Get Dashboard Data
Retrieves an aggregated overview of the bot's current state, including recent trades, signals, news, portfolio, and stats.

**Endpoint**: `GET /api/dashboard`

**Example Request**:
```bash
curl http://localhost:3000/api/dashboard
```

**Example Response**:
```json
{
  "trades": [
    {
      "id": "1",
      "symbol": "BTCUSDT",
      "action": "BUY",
      "price": 45000,
      "quantity": 0.1,
      "timestamp": "2023-10-27T10:00:00Z",
      "status": "OPEN"
    }
  ],
  "signals": [],
  "news": [],
  "portfolio": {
    "totalValue": 10000,
    "positions": [],
    "performance": {
      "totalPnl": 0,
      "totalPnlPercentage": 0,
      "winRate": 0,
      "totalTrades": 0
    }
  },
  "stats": {
    "uptime": 3600,
    "totalCommands": 150,
    "activeUsers": 5,
    "lastUpdate": "2023-10-27T10:05:00Z"
  }
}
```

### Get Trades
Retrieves a list of recent trades.

**Endpoint**: `GET /api/trades?limit={number}`

**Example Request**:
```bash
curl http://localhost:3000/api/trades?limit=10
```

**Example Response**:
```json
[
  {
    "id": "1",
    "symbol": "BTCUSDT",
    "action": "BUY",
    "price": 45000,
    "quantity": 0.1,
    "timestamp": "2023-10-27T10:00:00Z",
    "status": "OPEN"
  }
]
```
