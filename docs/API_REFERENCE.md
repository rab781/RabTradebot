# API Reference

The Advanced Crypto Trading Bot provides a REST API to access real-time market data, bot state, portfolio performance, and health metrics. This API is used by the Web Dashboard but can also be accessed by external integrations.

## Authentication
Currently, the REST API endpoints are public and **do not require authentication**.

## Rate Limiting
Requests are rate-limited to **100 requests per minute per IP address**.
If the limit is exceeded, you will receive a `429 Too Many Requests` response with the following body:
```json
{
  "error": "Too many requests, please try again later."
}
```

## Error Handling
For most endpoints, internal server errors will result in a `500 Internal Server Error` response with the following format:
```json
{
  "error": "An internal server error occurred"
}
```

## Pagination
Several list endpoints (e.g., `/api/trades`, `/api/signals`, `/api/news`) accept an optional `limit` query parameter. If omitted, the default values are:
- `trades`: 50
- `signals`: 20
- `news`: 20

---

## Endpoints

### Get Dashboard Data
Returns an aggregated view of the bot's state.

- **GET** `/api/dashboard`
- **Response**: `200 OK`
```json
{
  "trades": [],
  "signals": [],
  "news": [],
  "portfolio": {
    "totalValue": 10000,
    "positions": [],
    "performance": {
      "totalPnl": 0,
      "totalPnlPercentage": 0,
      "winRate": 0,
      "totalTrades": 0
    }
  },
  "stats": {
    "uptime": 3600,
    "totalCommands": 5,
    "activeUsers": 1,
    "lastUpdate": "2023-10-25T12:00:00.000Z"
  },
  "openTrades": []
}
```
- **Example**:
```bash
curl -X GET http://localhost:3000/api/dashboard
```

### Get Trades
Retrieves a list of recent trades.

- **GET** `/api/trades?limit={number}`
- **Query Params**:
  - `limit` (optional): Number of trades to return (default 50).
- **Response**: `200 OK`
```json
[
  {
    "id": "trade_123",
    "symbol": "BTCUSDT",
    "action": "BUY",
    "price": 30000,
    "quantity": 0.1,
    "timestamp": "2023-10-25T12:00:00.000Z",
    "profit": 150,
    "status": "CLOSED"
  }
]
```
- **Example**:
```bash
curl -X GET "http://localhost:3000/api/trades?limit=10"
```


### Get Signals
Retrieves recent trading signals generated by the bot.

- **GET** `/api/signals?limit={number}`
- **Query Params**:
  - `limit` (optional): Number of signals to return (default 20).
- **Response**: `200 OK`
```json
[
  {
    "symbol": "SOLUSDT",
    "action": "BUY",
    "price": 25.5,
    "confidence": 0.85,
    "timestamp": "2023-10-25T14:00:00.000Z",
    "indicators": {
      "rsi": 35,
      "macd": { "value": 1.2, "signal": 0.8 },
      "bbands": { "upper": 27, "middle": 25, "lower": 23 }
    }
  }
]
```
- **Example**:
```bash
curl -X GET "http://localhost:3000/api/signals?limit=5"
```

```json
    "sentiment": "BULLISH",
    "impact": "HIGH",
    "timestamp": "2023-10-25T10:00:00.000Z"

]
```
- **Example**:
```bash
curl -X GET "http://localhost:3000/api/news?limit=10"
```

### Get Detailed System Health

- **GET** `/health`
- **Response**: `200 OK` (or `503 Service Unavailable` if system is down)
```json
{
  "status": "ok",
  "timestamp": "2023-10-25T15:00:00.000Z",
  "uptime": 86400,
  "memoryUsageMb": 150.5,
  "requestCount": 150,
  "components": {
    "database": {
      "status": "ok",
      "lastCheck": 1698246000000,
      "message": "Connected"
    },
    "binanceRest": {
      "status": "ok",
      "lastCheck": 1698246000000,
      "message": "Latency: 45ms"
    }
  }
}
```
- **Example**:
```bash
curl -X GET http://localhost:3000/health
```
