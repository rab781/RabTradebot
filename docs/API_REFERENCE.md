# API Reference

The Advanced Crypto Trading Bot provides a REST API to access bot state, trading history, signals, and portfolio performance.

## Base URL

By default, the API is served locally:

```
http://localhost:3000
```

## Authentication

**No authentication is currently required** to access the API endpoints by default. Ensure the web server is not exposed to the public internet without a reverse proxy (like Nginx) handling authentication.

## Rate Limiting

The API enforces rate limiting per IP address:
- **Limit:** 100 requests per 60 seconds (1 minute).
- **Exceeded:** Returns HTTP `429 Too Many Requests` with a JSON response `{"error": "Too many requests, please try again later."}`.

## Pagination

Endpoints returning lists of data (like trades, signals, and news) support the `limit` query parameter to control the number of returned items. For example, `?limit=10`.
- `/api/trades`: Default limit is `50`.
- `/api/signals`: Default limit is `20`.
- `/api/news`: Default limit is `20`.

## Error Handling

General internal server errors return HTTP `500 Internal Server Error` with:
```json
{
  "error": "An internal server error occurred"
}
```

### 2. Get Trades
Retrieves a list of recent trades.

- **URL**: `/api/trades`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (optional): Number of trades to return (default: `50`).
- **Response Example**:
```json
[
  {
    "id": "trade_123",
    "symbol": "BTCUSDT",
    "action": "BUY",
    "price": 50000,
    "quantity": 0.1,
    "timestamp": "2023-10-01T12:00:00.000Z",
    "status": "OPEN"
  }
]
```

### 3. Get Open Trades
Retrieves a list of currently open trades.

- **URL**: `/api/trades/open`
- **Method**: `GET`
- **Response Example**:
```json
[
  {
    "id": "trade_456",
    "symbol": "ETHUSDT",
    "action": "SELL",
    "price": 2500,
    "quantity": 1,
    "timestamp": "2023-10-01T12:30:00.000Z",
    "status": "OPEN"
  }
]
```

### 4. Get Signals
Retrieves recent trading signals generated by the bot.

- **URL**: `/api/signals`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (optional): Number of signals to return (default: `20`).
- **Response Example**:
```json
[
  {
    "symbol": "SOLUSDT",
    "action": "HOLD",
    "price": 140,
    "confidence": 0.6,
    "timestamp": "2023-10-01T12:45:00.000Z"
  }
]
```

### 5. Get News
Retrieves recent news items that might impact trading.

- **URL**: `/api/news`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (optional): Number of news items to return (default: `20`).
- **Response Example**:
```json
[
  {
    "symbol": "ETH",
    "title": "Ethereum upgrade announced",
    "sentiment": "BULLISH",
    "impact": "HIGH",
    "timestamp": "2023-10-01T11:00:00.000Z"
  }
]
```

### 6. Get Portfolio
Retrieves the current portfolio state, including open positions and performance metrics.

- **URL**: `/api/portfolio`
- **Method**: `GET`
- **Response Example**:
```json
{
  "totalValue": 10000,
  "positions": [],
  "performance": {
    "todayPnl": 0,
    "todayPnlPercentage": 0,
    "totalPnl": 0,
    "totalPnlPercentage": 0,
    "winRate": 0,
    "totalTrades": 0
  }
}
```

### 7. Get Bot Stats
Retrieves aggregate statistics for the bot's runtime.

- **URL**: `/api/stats`
- **Method**: `GET`
- **Response Example**:
```json
{
  "uptime": 86400,
  "totalCommands": 42,
  "activeUsers": 2,
  "lastUpdate": "2023-10-01T12:00:00.000Z"
}
```

### 8. API Health Check
Basic health endpoint.

- **URL**: `/api/health`
- **Method**: `GET`
- **Response Example**:
```json
{
  "status": "OK",
  "timestamp": "2023-10-01T12:00:00.000Z",
  "uptime": 86400
}
```

### 9. External Monitoring Health Check
Detailed health monitoring endpoint used for external systems.

- **URL**: `/health`
- **Method**: `GET`
- **Response Example**:
```json
{
  "status": "healthy",
  "timestamp": "2023-10-01T12:00:00.000Z",
  "uptime": 86400,
  "memoryUsageMb": 150.5,
  "requestCount": 42,
  "components": {
    "database": "healthy",
    "binance_api": "healthy"
  }
}
```

## Working Example

Here is a `curl` command to test the API and retrieve 5 recent trades:

```bash
curl -X GET "http://localhost:3000/api/trades?limit=5" -H "Accept: application/json"
```
