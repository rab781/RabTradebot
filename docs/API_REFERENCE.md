# API Reference

The Advanced Crypto Trading Bot provides a public REST API under the `/api` route.
The endpoints allow developers to query the bot's current state, including active trades, portfolio status, signals, and news.

## Authentication
Currently, the REST API endpoints under `/api` do not require authentication headers. They are public endpoints for querying dashboard data.

## Rate Limiting
All `/api` routes are protected by a global rate limiter:
- **Limit:** 100 requests per minute per IP address.
- **Error Response:** If the limit is exceeded, the server responds with an HTTP `429 Too Many Requests` status and the following JSON payload:
  ```json
  {
    "error": "Too many requests, please try again later."
  }
  ```

## General Error Handling
If an internal server error occurs during the processing of a request, the API will respond with an HTTP `500 Internal Server Error` status and the following JSON payload:
```json
{
  "error": "An internal server error occurred"
}
```

### 2. Get Trades
Retrieves a list of recent trades executed by the bot.

**Endpoint:** `GET /api/trades`

**Query Parameters:**
- `limit` (optional, number): Maximum number of trades to return. Defaults to 50.

**Example Request:**
```bash
curl "http://localhost:3000/api/trades?limit=5"
```

**Response:**
Returns an HTTP `200 OK` with an array of trade objects.
```json
[
  {
    "id": "uuid-string",
    "symbol": "BTC/USDT",
    "action": "BUY",
    "price": 50000,
    "quantity": 0.1,
    "timestamp": "2023-10-27T10:00:00.000Z",
    "profit": 100,
    "status": "CLOSED"
  }
]
```

### 9. External Monitoring Health Check
A comprehensive health check endpoint intended for external monitoring systems. Includes status for internal components.

**Endpoint:** `GET /health`

**Note:** This endpoint is NOT subject to the `/api` rate limiter.

**Example Request:**
```bash
curl http://localhost:3000/health
```

**Response:**
Returns an HTTP `200 OK` (if healthy) or `503 Service Unavailable` (if down), along with detailed component status.
```json
{
  "status": "up",
  "timestamp": "2023-10-27T10:00:00.000Z",
  "uptime": 3600,
  "memoryUsageMb": 150,
  "requestCount": 150,
  "components": {
    "database": { "status": "up", "lastCheck": 1698393600000 },
    "exchange": { "status": "up", "lastCheck": 1698393600000 },
    "telegram": { "status": "up", "lastCheck": 1698393600000 }
  }
}
```
