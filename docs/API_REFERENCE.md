# API Reference

The REST API allows you to retrieve real-time state, trades, signals, and news from the RabTradebot system.

## Rate Limiting
Requests are limited to 100/minute per IP address. Rate limit headers are included in every response. When the limit is exceeded, the API returns a `429 Too Many Requests` response.

## Authentication
Currently, the REST API endpoints are unauthenticated and intended for read-only monitoring and dashboards running on a secure network. Do not expose these endpoints directly to the public internet without a reverse proxy adding authentication.

## Endpoints

### Get Dashboard Data
Retrieves an aggregated snapshot of the bot's current state, including portfolio value, open trades, and recent signals.

**Endpoint:** `GET /api/dashboard`

**Responses:**
- `200 OK`: Returns the dashboard data object.
- `429 Too Many Requests`: Rate limit exceeded.
- `500 Internal Server Error`: An error occurred.

### Get Trades
Retrieves a list of recent trades executed by the bot.

**Endpoint:** `GET /api/trades`

**Query Parameters:**
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | `number` | `50` | Maximum number of trades to return |

**Responses:**
- `200 OK`: Returns an array of trade objects.
- `429 Too Many Requests`: Rate limit exceeded.

### Get Open Trades
Retrieves a list of currently open trades.

**Endpoint:** `GET /api/trades/open`

**Responses:**
- `200 OK`: Returns an array of open trade objects.
- `429 Too Many Requests`: Rate limit exceeded.

### Get Signals
Retrieves a list of recent trading signals generated by the bot.

**Endpoint:** `GET /api/signals`

**Query Parameters:**
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | `number` | `20` | Maximum number of signals to return |

**Responses:**
- `200 OK`: Returns an array of signal objects.
- `429 Too Many Requests`: Rate limit exceeded.

### Get News
Retrieves recently analyzed news items and their predicted market impact.

**Endpoint:** `GET /api/news`

**Query Parameters:**
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | `number` | `20` | Maximum number of news items to return |

**Responses:**
- `200 OK`: Returns an array of news objects.
- `429 Too Many Requests`: Rate limit exceeded.

### Get Portfolio
Retrieves the current portfolio balance and asset allocation.

**Endpoint:** `GET /api/portfolio`

**Responses:**
- `200 OK`: Returns the portfolio state object.
- `429 Too Many Requests`: Rate limit exceeded.

### Get Bot Statistics
Retrieves performance statistics such as win rate, total profit, and uptime.

**Endpoint:** `GET /api/stats`

**Responses:**
- `200 OK`: Returns the bot statistics object.
- `429 Too Many Requests`: Rate limit exceeded.

### System Health
Retrieves basic health information for load balancers and simple monitoring.

**Endpoint:** `GET /api/health`

**Responses:**
- `200 OK`: Returns `{"status": "OK", "timestamp": "...", "uptime": ...}`.

### Detailed Health Monitoring
Retrieves a detailed system health snapshot including service status and error rates.

**Endpoint:** `GET /health`

**Responses:**
- `200 OK`: Returns the system health snapshot.
- `503 Service Unavailable`: Returned if overall status is 'error' or 'critical'.
