# Advanced Crypto Trading Bot API Reference

The Advanced Crypto Trading Bot Web Server provides a REST API and WebSocket events for real-time updates of trading bot state.

## Base URL
All API requests should be prefixed with the base URL, which defaults to `http://localhost:3000`.

## Authentication
The REST API currently runs without authentication. There is no API key or token required to access these endpoints.

## Rate Limiting
The API enforces a rate limit to prevent abuse.
* **Limit**: 100 requests per minute per IP address.
* **Exceeded Limit**: If the limit is exceeded, the API responds with an HTTP `429 Too Many Requests` status and the following JSON payload:
```json
{
  "error": "Too many requests, please try again later."
}
```

## Pagination
Some endpoints (like `/api/trades`, `/api/signals`, and `/api/news`) support a `limit` query parameter to paginate or constrain the number of returned records.
* `?limit=N` limits the response to the most recent `N` records.

## General Error Handling
If an unexpected server error occurs during processing, the API responds with an HTTP `500 Internal Server Error` status and the following JSON payload:
```json
{
  "error": "An internal server error occurred"
}
```

### 2. Get Trades
Retrieves the history of recent trades.

**Endpoint:** `GET /api/trades`

**Query Parameters:**
* `limit` (optional): Number of trades to return (default: `50`).

**Example Request:**
```bash
curl -X GET "http://localhost:3000/api/trades?limit=2"
```
