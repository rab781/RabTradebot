# Advanced Crypto Trading Bot API Reference

> REST API documentation for accessing trading bot state, performance metrics, and system health.

## Overview

The Advanced Crypto Trading Bot provides a local REST API that powers the web dashboard and allows external integrations to monitor the bot's state.

### Authentication

The API is intended for local dashboard access and **currently does not require authentication**. To restrict access, ensure that the API is not exposed to the public internet or is secured behind a reverse proxy (e.g., NGINX) with basic authentication or IP whitelisting.

### Rate Limiting

Requests to all `/api/*` endpoints are rate-limited to **100 requests per minute per IP address**.
When the limit is exceeded, the server will return an HTTP `429 Too Many Requests` status code with the following JSON payload:

```json
{
  "error": "Too many requests, please try again later."
}
```

### Pagination

Some endpoints support pagination via the `limit` query parameter.
- `/api/trades` defaults to a limit of `50`.
- `/api/signals` defaults to a limit of `20`.
- `/api/news` defaults to a limit of `20`.

### Error Handling

If an internal error occurs (e.g., failure to retrieve data), the server returns an HTTP `500 Internal Server Error` with the following JSON response:

```json
{
  "error": "An internal server error occurred"
}
```

---

## Example Usage

Here is a runnable example to fetch the latest trades using `curl`:

```bash
curl -X GET "http://localhost:3000/api/trades?limit=5" -H "Accept: application/json"
```

#### `GET /api/trades`
Retrieves a list of recent trades.

**Query Parameters**
- `limit` (optional): Number of trades to return (default: `50`).

**Response**
```json
[
  {
    "id": "trade-123",
    "symbol": "BTCUSDT",
    "action": "BUY",
    "price": 60000,
    "quantity": 0.1,
    "timestamp": "2023-10-01T12:00:00.000Z",
    "profit": 0,
    "status": "OPEN"
  }
]
```

#### `GET /api/trades/open`

**Response**

### System Health

#### `GET /api/health`
Basic health check endpoint for the API service.

**Response**
```json
{
  "status": "OK",
  "timestamp": "2023-10-01T12:05:00.000Z",
  "uptime": 3600.5
}
```
