# Advanced Crypto Trading Bot API Reference

> REST API for the Trading Bot Web Dashboard, providing real-time metrics, trades, signals, and system health status.

## Overview

The Web Dashboard API allows you to retrieve the current state of the trading bot. The API is read-only and designed to power monitoring dashboards.

### Authentication
The API currently does **not** require authentication. It is intended to be run locally or within a trusted, restricted network environment.

### Rate Limiting
Requests to `/api/*` endpoints are limited to **100 requests per minute per IP**. If you exceed this limit, the API will respond with:

| Code | Description |
|------|-------------|
| `429` | Too many requests, please try again later. |

### Pagination
List endpoints accept a `limit` query parameter to control the number of returned items.

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `limit`| `number` | varies | Maximum number of records to return |

### Error Handling
In the event of an internal server error, endpoints will return:

| Code | Description |
|------|-------------|
| `500` | An internal server error occurred |

## Endpoints

### Get Dashboard Summary
Retrieves a high-level summary of the bot's current status and performance.

**GET** `/api/dashboard`

#### Response
Returns a JSON object representing the dashboard data structure from the bot state.

### Get Recent Trades
Retrieves a list of completed trades.

**GET** `/api/trades`

#### Query Parameters
| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `limit`| `number` | `50` | Maximum number of trades to return |

#### Response
Returns a JSON array of trade objects.

### Get Open Trades
Retrieves all currently active trading positions.

**GET** `/api/trades/open`

#### Response
Returns a JSON array of active trade objects.

### Get Signals
Retrieves recent trading signals generated by the bot's analysis engine.

**GET** `/api/signals`

#### Query Parameters
| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `limit`| `number` | `20` | Maximum number of signals to return |

#### Response
Returns a JSON array of signal objects.

### Get News
Retrieves recent AI-analyzed news items affecting the market.

**GET** `/api/news`

#### Query Parameters
| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `limit`| `number` | `20` | Maximum number of news items to return |

#### Response
Returns a JSON array of news objects.

### Get Portfolio
Retrieves the current portfolio balance and asset allocation.

**GET** `/api/portfolio`

#### Response
Returns a JSON object representing the portfolio data structure.

### Get Bot Stats
Retrieves operational statistics including command usage and error counts.

**GET** `/api/stats`

#### Response
Returns a JSON object representing bot statistics.

### Get API Health
Simple health check endpoint for the web server.

**GET** `/api/health`

#### Response
```json
{
  "status": "OK",
  "timestamp": "2023-10-27T10:00:00.000Z",
  "uptime": 3600.5
}
```

### Get System Health Snapshot
Comprehensive health monitoring endpoint combining web server and core bot metrics. Used for external monitoring. Note: This endpoint is not rate limited.

**GET** `/health`

#### Response
Returns HTTP `200` if overall status is `up`, or `503` if overall status is `down`, along with a JSON object:
```json
{
  "status": "up",
  "timestamp": "2023-10-27T10:00:00.000Z",
  "uptime": 3600.5,
  "memoryUsageMb": 150.2,
  "requestCount": 42,
  "components": {}
}
```
