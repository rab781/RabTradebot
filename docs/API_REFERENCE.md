# RabTradebot API Reference

The RabTradebot provides a REST API for accessing trading data, signals, and bot state.

## Base URL
Local development: `http://localhost:3000/api`

## Authentication
Currently, the REST API does not require authentication.

## Rate Limiting
Requests are rate-limited to **100 requests per minute per IP address**. Exceeding this limit will result in a `429 Too Many Requests` HTTP response.

## Pagination
List endpoints accept a `limit` query parameter to restrict the number of results returned.
- Default limit for `/api/trades`: 50
- Default limit for `/api/signals` and `/api/news`: 20

---

### 2. Get All Trades
Retrieves a list of recent trades.

- **URL**: `/api/trades`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (optional, default: 50): Maximum number of trades to return.
- **Example Request**:
  ```bash
  curl -X GET 'http://localhost:3000/api/trades?limit=5'
  ```
- **Example Response**:
  ```json
  [
    {
      "id": "1",
      "symbol": "BTCUSDT",
      "action": "BUY",
      "price": 50000,
      "quantity": 0.1,
      "timestamp": "2023-10-25T12:00:00Z",
      "profit": 150.5,
      "status": "CLOSED"
    }
  ]
  ```

### 9. System Health Monitor
Detailed endpoint reporting the health of internal components (e.g., Database, Binance API). Note this endpoint is mapped to `/health`, not `/api/health`.

- **URL**: `/health`
- **Method**: `GET`
- **Query Parameters**: None
- **Example Request**:
  ```bash
  curl -X GET http://localhost:3000/health
  ```
- **Example Response**:
