# Advanced Crypto Trading Bot - API Reference

> REST API reference for accessing bot state, trading data, and market analysis.

## Base URL
All API requests should be made to `http://localhost:<PORT>` (or your configured server domain).

## Authentication
The API by default runs **without authentication** for local network access. (In future updates, authentication may be implemented for public exposure).

## Rate Limiting
Requests are limited to **100 requests/minute per IP**. If you exceed this limit, the server will return an HTTP `429 Too Many Requests` status code.

## Pagination
List endpoints like `/api/trades`, `/api/signals`, and `/api/news` support pagination via the `limit` query parameter.
- Default limit for `/api/trades` is **50**.
- Default limit for `/api/signals` and `/api/news` is **20**.

## Error Handling
In the event of an internal error, the API returns a `500 Internal Server Error` status code with the following JSON structure:
```json
{
  "error": "An internal server error occurred"
}
```

### Get Trades
Retrieves a list of recent trades.

**Endpoint:** `GET /api/trades`

**Query Parameters:**
- `limit` (optional): Number of trades to return. Default is 50.

**Example Request:**
```bash
curl -X GET "http://localhost:3000/api/trades?limit=10"
```

**Example Response (200 OK):**
```json
[
  {
    "id": "trade_123",
    "symbol": "BTCUSDT",
    "action": "BUY",
    "price": 42000.5,
    "quantity": 0.1,
    "timestamp": "2023-10-25T10:00:00.000Z",
    "profit": 0,
    "status": "OPEN"
  }
]
```

**Endpoint:** `GET /api/health`


### External Monitoring Health
Provides a comprehensive system health snapshot for external monitoring tools, including memory usage and component statuses. Returns a `503 Service Unavailable` status code if the overall state is 'down'.

**Endpoint:** `GET /health`

**Example Request:**
```bash
curl -X GET http://localhost:3000/health
```

**Example Response (200 OK):**
```json
{
  "status": "operational",
  "timestamp": "2023-10-25T10:05:00.000Z",
  "uptime": 3600000,
  "memoryUsageMb": 150.5,
  "requestCount": 150,
  "components": {
    "database": { "status": "up", "latency": 15 },
    "binance": { "status": "up", "latency": 45 }
  }
}
```
