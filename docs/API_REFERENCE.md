# REST API Reference

The Trading Bot Dashboard API provides real-time access to trading data, portfolio state, signals, and bot health.

## Authentication
Currently, the REST API runs without authentication. It is intended for local or internal network use. Ensure you secure the dashboard behind a reverse proxy or VPN if exposing it to the public internet.

## Rate Limiting
Requests are limited to 100 per minute per IP address. Rate limits are enforced on all `/api/*` endpoints.

- **HTTP 429 Too Many Requests**: Returned when the rate limit is exceeded.
  ```json
  {
    "error": "Too many requests, please try again later."
  }
  ```

## Pagination
List endpoints support pagination via the `limit` query parameter.

## Endpoints

### Get Dashboard Data
Retrieves an aggregated summary of the bot's state.

**Endpoint:** `GET /api/dashboard`

**Responses:**
- **200 OK**: Returns dashboard summary.
- **500 Internal Server Error**: If data retrieval fails.
  ```json
  {
    "error": "An internal server error occurred"
  }
  ```

---

### Get Trades
Retrieves recent trades executed by the bot.

**Endpoint:** `GET /api/trades`

**Query Parameters:**
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | `number` | `50` | Maximum number of trades to return |

**Responses:**
- **200 OK**: Returns an array of trades.
- **500 Internal Server Error**: If data retrieval fails.

---

### Get Open Trades
Retrieves all currently active (open) trades.

**Endpoint:** `GET /api/trades/open`

**Responses:**
- **200 OK**: Returns an array of open trades.
- **500 Internal Server Error**: If data retrieval fails.

---

### Get Signals

**Endpoint:** `GET /api/signals`

**Query Parameters:**
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | `number` | `20` | Maximum number of signals to return |

**Responses:**
- **200 OK**: Returns an array of signals.
- **500 Internal Server Error**: If data retrieval fails.

---

### Get News
Retrieves recently processed news and their AI sentiment analysis.

**Endpoint:** `GET /api/news`

**Query Parameters:**
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | `number` | `20` | Maximum number of news items to return |

**Responses:**
- **200 OK**: Returns an array of news items.
- **500 Internal Server Error**: If data retrieval fails.

---

### Get Portfolio
Retrieves the current portfolio balance and positions.

**Endpoint:** `GET /api/portfolio`

**Responses:**
- **200 OK**: Returns portfolio details.
- **500 Internal Server Error**: If data retrieval fails.

---

### Get Bot Stats
Retrieves operational statistics for the bot (e.g., uptime, total commands processed).

**Endpoint:** `GET /api/stats`

**Responses:**
- **200 OK**: Returns bot statistics.
- **500 Internal Server Error**: If data retrieval fails.

---

### Get API Health
Simple health check for the API.

**Endpoint:** `GET /api/health`

**Responses:**
- **200 OK**: Returns the API status.
  ```json
  {
    "status": "OK",
    "timestamp": "<current date/time>",
    "uptime": <process.uptime()>
  }
  ```

---

### Get System Health (External Monitoring)
Detailed health check intended for external monitoring tools.

**Endpoint:** `GET /health`

**Responses:**
- **200 OK**: System is fully operational.
- **503 Service Unavailable**: One or more critical components are down.
  ```json
  {
    "status": "overallStatus",
    "timestamp": "ISO 8601 string",
    "uptime": "<uptime>",
    "memoryUsageMb": "<memoryUsageMb>",
    "requestCount": "<stats.totalCommands>",
    "components": "<components>"
  }
  ```
