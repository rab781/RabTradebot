# RabTradebot API Reference

The RabTradebot Web Dashboard API provides access to the bot's state, trades, signals, news, and system health.

## Authentication
This REST API currently **does not require authentication**.

## Rate Limiting
Requests are rate-limited to **100 requests per minute per IP address**.
If the limit is exceeded, you will receive a `429 Too Many Requests` response.

## Pagination
Endpoints that return lists (such as trades, signals, and news) support a `limit` query parameter to control the number of items returned.
- `/api/trades` defaults to 50 items.
- `/api/signals` and `/api/news` default to 20 items.

## General Error Handling
Failed requests will return standard HTTP status codes:
- `429 Too Many Requests` if rate limits are exceeded.
- `500 Internal Server Error` if the server encounters an unexpected error.
Error responses generally follow this format:
```json
{
  "error": "An internal server error occurred"
}
```

## Endpoints

### Get Dashboard Data
Retrieves an aggregate payload containing recent trades, signals, news, portfolio status, bot stats, and open trades.
**GET** `/api/dashboard`

**Example Request:**
```bash
curl -X GET http://localhost:3000/api/dashboard
```

**Example Response:**
```json
{
  "trades": [
    {
      "id": "123",
      "symbol": "BTCUSDT",
      "action": "BUY",
      "price": 60000,
      "quantity": 0.1,
      "timestamp": "2023-10-01T12:00:00.000Z",
      "profit": 0,
      "status": "OPEN"
    }
  ],
  "signals": [],
  "news": [],
  "portfolio": {
    "totalValue": 10000,
    "positions": [],
    "performance": {
      "totalPnl": 0,
      "totalPnlPercentage": 0,
      "winRate": 0,
      "totalTrades": 0
    }
  },
  "stats": {
    "uptime": 3600000,
    "totalCommands": 10,
    "activeUsers": 1,
    "lastUpdate": "2023-10-01T13:00:00.000Z"
  },
  "openTrades": []
}
```

### Get Trades
Retrieves a list of recent trades.
**GET** `/api/trades?limit=50`

**Example Request:**
```bash
curl -X GET "http://localhost:3000/api/trades?limit=5"
```

**Example Response:**
```json
[
  {
    "id": "trade_1",
    "symbol": "ETHUSDT",
    "action": "SELL",
    "price": 3000,
    "quantity": 1,
    "timestamp": "2023-10-01T12:30:00.000Z",
    "profit": 50,
    "status": "CLOSED"
  }
]
```
