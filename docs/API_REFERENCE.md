# Advanced Crypto Trading Bot API Reference

The Advanced Crypto Trading Bot provides a REST API to retrieve real-time state, trades, signals, and system health. This API is intended for read-only monitoring and powers the Web Dashboard.

## Authentication
Currently, the REST API does not require authentication.

## Rate Limiting
Requests are rate-limited to **100 requests per minute per IP address**.
If you exceed this limit, you will receive a `429 Too Many Requests` response:
```json
{
  "error": "Too many requests, please try again later."
}
```

## Base URL
The API runs on the web server port, which defaults to `3000`.
Base URL for most endpoints: `http://localhost:3000/api`

---

### 2. Get Trades
Retrieves a list of recent trades (both open and closed).

- **URL:** `/api/trades`
- **Method:** `GET`
- **Query Parameters:**
  - `limit` (optional): Number of trades to return (default: `50`, max enforced by internal array cap: `100`).

**Example Request:**
```bash
curl "http://localhost:3000/api/trades?limit=10"
```

**Example Response:**
```json
[
  {
    "id": "1",
    "symbol": "BTCUSDT",
    "action": "BUY",
    "price": 65000,
    "quantity": 0.1,
    "timestamp": "2023-10-27T10:00:00Z",
    "status": "OPEN"
  }
]
```

### 9. Detailed System Health
An external monitoring endpoint that provides a detailed health snapshot of various internal components.

- **URL:** `/health` *(Note: This is outside the `/api` prefix)*
- **Method:** `GET`
- **Pagination:** None

**Response Codes:**
- `200 OK`: All components are operational or degraded (but system is up).
- `503 Service Unavailable`: One or more components are down, leading to an overall `down` status.

**Example Request:**
```bash
curl http://localhost:3000/health
```

**Example Response:**
```json
{
  "status": "ok",
  "timestamp": "2023-10-27T10:20:00.000Z",
  "uptime": 3605,
  "memoryUsageMb": 150.2,
  "requestCount": 45,
  "components": {
    "database": {
      "status": "ok",
      "lastCheck": 1698402000000,
      "message": "Connected"
    },
    "binanceWs": {
      "status": "ok",
      "lastCheck": 1698402000000,
      "message": "Connected"
    }
  }
}
```
