# REST API Reference

The RabTradebot provides a REST API to access bot status, trades, signals, news, and overall dashboard metrics.

## Authentication
The REST API currently operates without authentication. Requests do not require any API keys or tokens. However, it is restricted by CORS and rate limits to ensure safe usage.

## Rate Limiting
Requests are limited to 100 requests per minute per IP address. Rate limiting is enforced across all `/api/*` endpoints.
When the rate limit is exceeded, the server responds with:
- **HTTP Status Code**: 429 Too Many Requests
- **Response**: `{"error": "Too many requests, please try again later."}`

## Pagination
List endpoints such as `/api/trades`, `/api/signals`, and `/api/news` support pagination via the `limit` query parameter:
- **limit**: Maximum number of records to return. Defaults are specific to each endpoint (e.g., 50 for trades, 20 for signals/news).

## General Error Handling
In the event of an internal error, endpoints will return:
- **HTTP Status Code**: 500 Internal Server Error
- **Response**: `{"error": "An internal server error occurred"}`

## Endpoints

### Get Dashboard Data
Returns an aggregated snapshot of the bot's current state.
- **URL**: `/api/dashboard`
- **Method**: `GET`
- **Response Structure**: JSON object containing bot metrics and current operations.

### Get Trades
Returns a list of recent trades executed by the bot.
- **URL**: `/api/trades`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (optional): integer (default 50).
- **Response Structure**: JSON array of trade objects.

### Get Open Trades
Returns the currently open positions.
- **URL**: `/api/trades/open`
- **Method**: `GET`
- **Response Structure**: JSON array of open trade objects.

### Get Signals
Returns recent trading signals generated by the bot.
- **URL**: `/api/signals`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (optional): integer (default 20).
- **Response Structure**: JSON array of signal objects.

### Get News
Returns recent news articles analyzed by the bot.
- **URL**: `/api/news`
- **Method**: `GET`
- **Query Parameters**:
  - `limit` (optional): integer (default 20).
- **Response Structure**: JSON array of news objects.

### Get Portfolio
Returns the current portfolio balances and performance.
- **URL**: `/api/portfolio`
- **Method**: `GET`
- **Response Structure**: JSON object detailing the portfolio.

### Get Bot Stats
Returns general bot statistics and performance indicators.
- **URL**: `/api/stats`
- **Method**: `GET`
- **Response Structure**: JSON object of bot statistics.

### Health Check (Internal)
Basic health verification.
- **URL**: `/api/health`
- **Method**: `GET`
- **Response Structure**:
  ```json
  {
    "status": "OK",
    "timestamp": "2023-10-01T12:00:00.000Z",
    "uptime": 1234.56
  }
  ```

### External Health Check
Returns detailed system and bot component health status.
- **URL**: `/health`
- **Method**: `GET`
- **Response Codes**:
  - 200 OK: System is operational.
  - 503 Service Unavailable: One or more components are down.
