# API Reference

The Advanced Crypto Trading Bot provides a REST API for accessing trading data, bot state, and health metrics.

## Authentication
Currently, the REST API runs without authentication. It is intended to be accessed locally or behind a secure reverse proxy.

## Rate Limiting
Requests are limited to 100/minute per IP address. Rate limit status is tracked internally.
When the limit is exceeded, the server responds with a `429 Too Many Requests` HTTP status code and a JSON error message: `{"error": "Too many requests, please try again later."}`.

## Pagination
Several endpoints support pagination via the `limit` query parameter.
- Trades: Default limit is 50.
- Signals: Default limit is 20.
- News: Default limit is 20.

## Error Handling
The API returns standard HTTP status codes.
- `200 OK`: Request successful.
- `400 Bad Request`: Invalid request parameters.
- `429 Too Many Requests`: Rate limit exceeded.
- `500 Internal Server Error`: An unexpected error occurred. Errors return a JSON object, e.g., `{"error": "An internal server error occurred"}`.
- `503 Service Unavailable`: Returned by the `/health` endpoint when the overall system status is down.

## Endpoints

### Dashboard Data
Retrieves consolidated dashboard information including overall state, summary statistics, recent trades, and open positions.

**Endpoint:** `GET /api/dashboard`
**Example Request:**
```bash
curl http://localhost:3000/api/dashboard
```
**Response (200):** JSON object containing dashboard data.

### Trades
Retrieves historical trades.

**Endpoint:** `GET /api/trades`
**Query Parameters:**
- `limit` (optional, number): Number of trades to return (Default: 50)
**Example Request:**
```bash
curl "http://localhost:3000/api/trades?limit=5"
```
**Response (200):** JSON array of trade objects.

### Open Trades
Retrieves currently open trades.

**Endpoint:** `GET /api/trades/open`
**Response (200):** JSON array of open trade objects.

### Signals
Retrieves recent trading signals generated by the bot.

**Endpoint:** `GET /api/signals`
**Query Parameters:**
- `limit` (optional, number): Number of signals to return (Default: 20)
**Example Request:**
```bash
curl "http://localhost:3000/api/signals?limit=5"
```
**Response (200):** JSON array of signal objects.

### News
Retrieves recent AI-analyzed news items.

**Endpoint:** `GET /api/news`
**Query Parameters:**
- `limit` (optional, number): Number of news items to return (Default: 20)
**Response (200):** JSON array of news objects.

### Portfolio
Retrieves current portfolio balance and asset allocations.

**Endpoint:** `GET /api/portfolio`
**Response (200):** JSON object containing portfolio details.

### Bot Stats
Retrieves operational statistics of the bot.

**Endpoint:** `GET /api/stats`
**Response (200):** JSON object containing bot statistics.

### API Health
Simple health check endpoint returning system uptime.

**Endpoint:** `GET /api/health`
**Response (200):**
```json
{
  "status": "OK",
  "timestamp": "2023-10-27T10:00:00.000Z",
  "uptime": 12345.67
}
```

### External Monitoring Health
Comprehensive health check endpoint for external monitoring systems, providing memory usage and component status.

**Endpoint:** `GET /health`
**Response (200 or 503):**
```json
{
  "status": "operational",
  "timestamp": "2023-10-27T10:00:00.000Z",
  "uptime": 12345.67,
  "memoryUsageMb": 150.5,
  "requestCount": 42,
  "components": {}
}
```
