# Advanced Crypto Trading Bot API Reference

> Comprehensive reference for the Advanced Crypto Trading Bot REST API, providing real-time trading data, signals, and portfolio statistics.

## Authentication
Currently, the API runs without authentication. All endpoints are open for local or configured dashboard access.

## Rate Limiting
Requests are limited to **100 requests per minute** per IP address. If this limit is exceeded, the server will return a `429 Too Many Requests` response.

## Pagination
Some endpoints support pagination via the `limit` query parameter:
- `/api/trades`: defaults to `50`
- `/api/signals`: defaults to `20`
- `/api/news`: defaults to `20`

## Error Handling
In case of an internal server error, endpoints return a `500 Internal Server Error` with the following payload structure:
```json
{
  "error": "An internal server error occurred"
}
```

## Endpoints

### GET `/api/dashboard`
Returns an aggregated view of the dashboard state, including trades, signals, news, portfolio, and stats.

**Example Request:**
```bash
curl -X GET http://localhost:3000/api/dashboard
```

**Example Response (200 OK):**
```json
{
  "trades": [
    {
      "id": "trade_1",
      "symbol": "BTC/USDT",
      "action": "BUY",
      "price": 60000,
      "quantity": 0.1,
      "timestamp": "2024-01-01T12:00:00.000Z",
      "profit": 150,
      "status": "CLOSED"
    }
  ],
  "signals": [],
  "news": [],
  "portfolio": {
    "totalValue": 10150,
    "positions": [],
    "performance": {
      "totalPnl": 150,
      "totalPnlPercentage": 1.5,
      "winRate": 1.0,

    "lastUpdate": "2024-01-01T12:05:00.000Z"
  },

}
```

### GET `/api/trades`
Returns a list of trades, ordered by most recent first.

**Query Parameters:**
- `limit` (optional, integer): Number of trades to return (default: 50).

**Example Request:**
```bash
curl -X GET "http://localhost:3000/api/trades?limit=5"
```

**Example Response (200 OK):**
```json
[
  {
    "id": "trade_1",
    "symbol": "BTC/USDT",
    "action": "BUY",
    "price": 60000,
    "quantity": 0.1,
    "timestamp": "2024-01-01T12:00:00.000Z",
    "profit": 150,
    "status": "CLOSED"
  }
]
```
